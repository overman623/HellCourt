# UI Spec

> 지옥법정 HTML5 MVP의 UI 구성 및 비주얼 방향을 정의한다.
> 구현 시 본 문서와 제공된 UI 레퍼런스를 우선한다.

---

# 1. 기본 방향

지옥법정의 MVP UI는 판사석에서 재판장을 바라보는
1인칭 시점을 기본으로 한다.

전체 화면은 사무적인 재판 시스템과
지옥의 비현실적인 분위기가 동시에 느껴지는 방향으로 구성한다.

MVP에서는 제작 효율과 시인성을 우선하여
제한된 색상과 단순한 형태를 사용한다.

---

# 2. 비주얼 스타일

기본 스타일:

- 검은색 배경
- 흰색 경계선
- 흰색 중심의 텍스트
- 단순한 사각형 UI 프레임
- 픽셀 스타일 캐릭터 및 오브젝트
- 장식보다 정보 전달과 실루엣 우선
- 전체적으로 낮은 색상 사용량

기본 재판 화면에서는 흑백을 중심으로 표현한다.

색상은 중요한 상태, 판결, 특수 연출 등
강조가 필요한 경우에 제한적으로 사용할 수 있다.

MVP 단계에서는 복잡한 애니메이션이나
과도한 UI 장식을 사용하지 않는다.

---

# 3. 기본 화면 구조

재판 화면은 크게 네 영역으로 구성한다.

## 좌측 — ACTION

플레이어가 재판 중 수행할 수 있는 행동을 배치한다.

주요 기능:

- 현재 법정/재판 정보
- 망자 이미지 또는 간단한 정보
- 인생사건 선택
- 심문하기
- 판결하기
- 메뉴
- 남은 법정 시간

`금일 망자`, `망자 프로필` 등의 보조 기능은
향후 별도 아이콘 또는 작은 UI로 변경할 수 있다.

---

## 중앙 — COURT

재판 현장을 보여주는 가장 중요한 시각 영역이다.

플레이어가 판사석에 앉아
법정을 바라보는 시점을 표현한다.

배치 가능한 요소:

- 현재 재판 중인 망자
- 검사
- 변호사
- 서기관
- 법정경위
- 증거관리인
- 방청 중인 망자
- 시계 및 법정 오브젝트

중앙 영역은 단순한 배경 이미지가 아니라
재판 상황과 등장인물의 상태를 전달하는 공간으로 사용한다.

상황에 따라 캐릭터 강조, 시선 이동,
대화 대상 강조 등의 연출을 추가할 수 있다.

---

## 우측 상단 — CONTEXT

현재 플레이어가 수행하고 있는 행동에 따라
내용이 변경되는 동적 정보 영역이다.

예:

- 망자의 대사
- 프로필
- 선택한 인생사건
- 사건의 기본 정보
- 조사 결과
- 심문 결과
- 판결 관련 정보

화면 전체를 교체하지 않고
이 영역의 내용을 변경하여 정보를 제공하는 것을 기본으로 한다.

---

## 우측 하단 — RECORD

플레이어가 지금까지 확인한 정보를
계속 참고할 수 있는 기록 영역이다.

현재 레퍼런스에서는 노트 형태로 표현한다.

주요 목적:

- 조사한 사건 확인
- 확보한 정보 확인
- 판단 근거 재확인
- 여러 인생사건 비교

CONTEXT 영역이 변경되더라도
RECORD 영역은 가능한 한 계속 접근할 수 있어야 한다.

플레이어가 판결 직전까지
자신이 조사한 내용을 다시 확인할 수 있도록 한다.

---

# 4. UI 역할 원칙

각 영역의 역할은 다음과 같이 구분한다.

LEFT
= 무엇을 할 것인가

CENTER
= 지금 누구를 재판하고 있는가

RIGHT TOP
= 지금 무엇을 보고 있는가

RIGHT BOTTOM
= 지금까지 무엇을 알아냈는가

이 역할 구분은 레이아웃 수정 시에도 가능한 한 유지한다.

---

# 5. 시간 표시

남은 법정 시간은 플레이어가
항상 확인할 수 있어야 한다.

MVP에서는 숫자 및 게이지 형태로 표시할 수 있다.

향후에는 재판장 내부의 시계 등
공간 자체를 활용한 UI로 변경할 수 있다.

정확한 하루 총 시간 및 시간 소비 규칙은
`GAME_RULES.md`를 따른다.

---

# 6. 금일 망자

플레이어는 오늘 판결해야 할
망자 목록을 확인할 수 있어야 한다.

MVP에서는 별도의 목록 UI 또는 팝업 형태로 구현할 수 있다.

표시 가능한 정보:

- 망자 이미지
- 이름 또는 식별 정보
- 남은 망자 수
- 현재 판결 진행 상태

세부 표현 방식은 구현 과정에서 변경할 수 있다.

---

# 7. 판결 UI

`판결하기`를 선택하면
천국 / 지옥 판결 단계로 전환한다.

판결 단계에서도 플레이어가 확보한 기록을
가능한 한 다시 확인할 수 있어야 한다.

판결 확정 후에는 재판장의 기본 UI보다
판결 결과와 망자의 반응을 강조한다.

천국 또는 지옥으로 이동하는 연출은
MVP에서도 중요한 시각적 보상으로 취급한다.

---

# 8. MVP 우선순위

MVP UI의 우선순위는 다음과 같다.

1. 플레이어 행동이 명확할 것
2. 망자와 재판 현장이 잘 보일 것
3. 현재 확인 중인 정보가 명확할 것
4. 기존 조사 기록을 언제든 다시 확인할 수 있을 것
5. 남은 시간을 쉽게 확인할 수 있을 것
6. 판결 과정이 명확할 것
7. 상세 장식 및 고급 연출

아트 완성도보다
전체 재판 플로우가 UI에서 정상적으로 작동하는 것을 우선한다.

---

# 9. 현재 변경 가능한 요소

다음 요소는 MVP 제작 과정에서 변경할 수 있다.

- 버튼 크기
- 버튼 위치
- 세부 패널 크기
- 폰트
- 캐릭터 크기
- 세부 픽셀아트 스타일
- 아이콘 형태
- 노트 디자인
- 보조 UI 위치

현재 UI 이미지는 최종 디자인이 아니라
레이아웃 및 분위기 레퍼런스로 취급한다.

단,

`ACTION / COURT / CONTEXT / RECORD`

의 역할 구분과

`판사석에서 재판장을 바라본다`

는 기본 경험은 우선적으로 유지한다.
