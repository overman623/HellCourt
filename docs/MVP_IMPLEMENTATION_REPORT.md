# 지옥법정 MVP — 구현 결과 / UI 보류 보고

스펙: `HellCourt_HTML5_MVP_Implementation_Spec.md`  
구현일: 2026-08-02

## 구현된 확정 규칙

- 재판 흐름: 이벤트 선택 → 질문 카드 사용 → 스탯 변화 → 해금 판정 → 공개 → 손패 교체
- 신뢰 / 스트레스 표시 및 카드 델타 적용
- FACT=사실 해금(신뢰 확률), EMOTION=감정 해금(스트레스 확률)
- 성공 시 **다음 미해금 정보만** 순서 공개 (랜덤 재추출 없음)
- 감정 연결 이벤트 확정 해금 (내용은 자동 공개하지 않음)
- 정체 사실 공개 시 이름 확정
- 손패 3장, 사용 후 1장 재공급, 최초 손패 FACT+EMOTION 최소 1장씩
- 영혼 파괴(스트레스 최대): 해당 질문 처리 후 심문 잠금 → 강제 판결
- 언제든 판결 가능, 유죄/무죄 + 이유 입력 (채점 없음)
- 판결 화면에서 확보 정보 재확인
- 플레이테스트 로그(콘솔 + JSON 다운로드)

## 모듈 / 토글

| 경로 | 역할 |
|------|------|
| `assets/data/game-config.js` | 시스템 on/off + 테스트용 수치 |
| `assets/data/game-content.js` | 망자/이벤트/카드 콘텐츠 |
| `assets/js/game.js` | 규칙 코어 (Stats/Unlock/Events/Hand/Soul/Log) |

`GAME_CONFIG.systems.*.enabled` 로 개별 시스템을 끌 수 있다.

## UI상 보류 / 애매해서 우선 처리한 것

1. **법정시간 게이지** — 스펙 미기재. `courtTimeGauge` 기본 OFF, UI 숨김.
2. **손패 5칸 아트 vs 규칙 3장** — 규칙은 3장으로 구현. 카드 슬롯 아트는 동일 레이아웃 유지.
3. **카드 아이콘 스프라이트** — 제공 이미지는 참고용. 속성은 FACT/EMO 텍스트 뱃지로 표시.
4. **사용 전 위험 경고 UI 위치** — 우측 하단 힌트 박스에 예상 확률·영혼 파괴 경고로 표시 (별도 모달 없음).
5. **질문 횟수 상한** — 스펙 §13 미확정. 미구현.
6. **연속 실패 보정** — `failStreakBonus.enabled: false` 자리만 확보.
7. **덱 고갈 시 교체 규칙** — 미확정. 임시로 discard 재셔플.
8. **설정 화면** — 인게임 옵션 UI 없음. config 파일 수정으로 대체.
9. **좌측 탭 명칭** — 기존 UI 유지. 사건=이벤트 목록, 상세=사실/감정 ??? 표시.
10. **사운드/고급 연출** — MVP 제외.

## 플레이 방법 (요약)

1. 타이틀 → 심판 시작  
2. 사건 정보에서 이벤트 선택 (Enter)  
3. → 로 질문 카드로 이동, Space로 사용  
4. 상세정보 탭에서 ??? / 공개 정보 확인  
5. 판결 버튼 또는 메뉴 → 유죄/무죄 + 이유
